# Third-party notices for `randoc-core`

This crate contains data from the projects below, in
`src/shared/tables.rs` and `src/shared/nfc_tables.rs`. Each project keeps its own licence. The rest of the
crate has the licence `MIT OR Apache-2.0`.

- The HTML entity table: `commonmark` 0.3.1 (BSD-3-Clause), which takes it from TagSoup (BSD-3-Clause).
- The ASCII table of CommonMark identifiers: `commonmark-extensions` 0.2.7.3 (BSD-3-Clause).
- The emoji alias tables: `emojis` 0.1.5 (BSD-3-Clause), with data from GitHub `gemoji` (MIT).
- The character classes and the ASCII forms of characters: the Unicode Character Database 15.1.0 and the canonical decompositions of Unicode 16.0.0 (Unicode License v3).
- The NFC tables: the Unicode Character Database 18.0.0 (Unicode License v3).
